## Why

当前五页运动学报告能够稳定呈现事实指标、规则型待复核发现和证据帧，但面向普通运动员时仍偏技术化，规则模板也难以结合多个指标形成易懂、连贯且有边界的说明。系统需要在不改变确定性计算结果的前提下，通过大模型 API 和经审核的游泳知识内容生成可追溯、可降级的通俗解读。

## What Changes

- 在确定性五页报告完成后增加异步 AI 解读阶段；基础报告先持久化并始终可用，大模型失败、超时或未配置时不得阻塞分析任务和报告访问。
- 从当前 `swim-report.v1` 中构造受控的解释输入，只包含指标值、单位、可用性、置信度、来源、待复核发现、证据帧、质量说明和必要的运动员/测试上下文，不由大模型重算或改写事实数据。
- 定义版本化的 AI 解读结构，包含通俗总结、分模块解释、优先关注项、条件式训练建议、复测目标、限制说明和逐条事实引用。
- 接入可替换的大模型 API provider，通过结构化输出 schema、超时、重试、内容护栏和结果校验约束生成行为。
- 建立经审核、可版本化的游泳知识内容注册与检索能力；按报告指标和发现检索相关知识片段，并将知识来源引用写入解读结果。
- 为 AI 解读保存生成状态、输入摘要、报告 generation signature、模型、provider、提示词版本、知识库版本、输出、错误信息和生成时间，支持复现、重新生成和失效判断。
- 在 Web 和 PDF 五页报告中展示同一份 ready AI 解读；生成中、不可用或失败时显示明确状态并保留原始指标、规则发现和五页结构。
- 增加自动事实一致性校验，禁止虚构数值、引用不存在的指标、把 unavailable 当作 0、生成未经支持的综合评分或把待复核发现改写为确定性诊断。
- 第一阶段不向大模型发送原始视频、完整逐帧关键点或未筛选的标注文件，不提供自由问答，不进行模型微调，也不允许大模型修改规则阈值或运动学计算结果。

## Capabilities

### New Capabilities

- `llm-assisted-report-interpretation`: 定义 AI 报告解读的输入投影、知识检索、异步生命周期、结构化输出、事实引用、护栏、追溯、重新生成和降级行为。

### Modified Capabilities

- `five-page-kinematics-report`: 扩展五页报告以关联和展示可选的 AI 解读状态与内容，同时保持确定性报告结构、来源事实和失败降级语义不变。

## Impact

- 后端：`annotation_kinematics` pipeline、报告 schema/读取 API、AI 解读服务与 provider adapter、知识内容注册与检索、持久化模型和迁移、配置与密钥管理。
- 前端：五页报告的 AI 解读区、生成中/失败/不可用状态、重新生成入口、事实与知识来源展示，以及打印布局。
- PDF：Web 与 PDF 共享同一份已持久化的 AI 解读，不在打印时重新调用模型。
- 数据与运维：新增大模型 API 依赖、调用超时与配额监控、敏感信息最小化、审计字段和 provider 可替换配置。
- 兼容性：现有 `swim-report.v1` 指标、规则发现、五页顺序和历史报告继续可读；AI 解读为可选增强，不构成 breaking change。
