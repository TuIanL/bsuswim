## Why

系统已经能够依据运动学指标自动选择并生成关键帧图片，但当前报告对这些图片的展示不够结构化，教练难以快速判断图片对应的动作问题、指标和视频位置。需要在现有五页报告中补充可读、可追溯的自动诊断关键帧证据，使“指标异常 → 证据画面 → 训练建议”形成闭环。

## What Changes

- 在报告资产模型中明确自动诊断关键帧的标题、指标值、单位、指标来源、标注帧和视频帧等展示语义。
- 在身体姿态、上肢技术和下肢技术报告页中增加关键帧证据区域，按模块和诊断含义组织展示。
- 继续沿用现有按指标极值选择关键帧的机制，不新增入水、抱水、推水、出水、移臂等动作阶段识别。
- 对关键帧缺失、指标不可用或资产生成失败的情况显示可解释的降级状态，不阻塞整份报告生成。
- 修复关键帧图片在报告/PDF中的中文字体、标题和信息显示问题，保证导出结果可读。
- 增加 Web 报告、打印页面和 PDF 导出的关键帧展示契约与回归测试。
- 不新增运动学指标，不改变现有指标计算公式、诊断阈值或五页报告页数。

## Capabilities

### New Capabilities

- `diagnostic-keyframe-evidence-display`: 在游泳技术分析报告中展示与运动学诊断关联的自动关键帧证据。

### Modified Capabilities

- `five-page-kinematics-report`: 报告页面需要按模块展示自动诊断关键帧，并保持五页结构、来源追溯和 PDF 一致性。
- `kinematics-visual-artifact-generation`: 关键帧资产需要提供稳定的展示元数据和可读的图片输出。

## Impact

- 后端报告资产投影、关键帧 presentation metadata 和报告页面组装逻辑。
- Vue 报告资产组件、报告数据归一化类型和打印页面布局。
- 关键帧图片渲染的字体/标题配置。
- Web 报告和 Playwright PDF 导出测试、报告资产契约测试。
- 不涉及数据库表结构变更；不改变现有视频上传、标注解析和运动学计算流程。
