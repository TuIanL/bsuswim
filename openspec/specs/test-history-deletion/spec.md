# test-history-deletion Specification

## Purpose
定义教练删除单条测试历史时，对关联业务数据和受控上传文件执行安全、不可恢复清理的要求。

## Requirements

### Requirement: 教练可硬删除自己的一条测试历史
系统 SHALL 提供 `DELETE /api/v1/sessions/{session_id}`，用于不可恢复地删除当前教练拥有的一条训练记录及其关联测试历史。

#### Scenario: 删除已完成的测试记录
- **WHEN** 当前教练请求删除自己一条已完成的训练记录
- **THEN** 系统 MUST 返回 `204 No Content`
- **AND** 该训练记录及其关联历史 MUST 不再通过会话、任务、工作台或报告 API 读取

#### Scenario: 删除草稿或仅上传视频的记录
- **WHEN** 当前教练请求删除自己一条没有运行中分析任务的草稿或已上传视频记录
- **THEN** 系统 MUST 删除该训练记录及已关联资源
- **AND** 系统 MUST 返回 `204 No Content`

#### Scenario: 拒绝删除他人的记录或不存在的记录
- **WHEN** 当前教练请求删除不存在的训练记录或不属于自己的训练记录
- **THEN** 系统 MUST 返回 `404`
- **AND** 系统 MUST 不泄露该记录的存在性或内容

### Requirement: 删除包含完整的数据库关联清理
系统 SHALL 在删除训练记录时清理其会话视频、标注文件、标准化标注、标注指标、运动学资产及资产集、复核结论、分析任务、分析结果、报告元数据和报告 AI 解读。

#### Scenario: 删除具有完整分析产物的记录
- **WHEN** 被删除记录具有关联标注、指标、资产、分析结果、报告和 AI 解读
- **THEN** 系统 MUST 删除全部关联数据库记录
- **AND** 系统 MUST 不保留引用已删除训练记录、任务、标注或指标的孤立记录

#### Scenario: 删除不存在的可选产物
- **WHEN** 被删除记录没有报告、标注或运动学资产中的任一种可选产物
- **THEN** 系统 MUST 继续删除其他存在的关联记录
- **AND** 系统 MUST 不因该缺失产物失败

### Requirement: 删除清理受控上传文件
系统 SHALL 根据关联记录登记的文件路径删除原始视频、标注文件、运动学资产和报告 PDF，且 MUST 仅删除解析后仍位于上传根目录内的路径。

#### Scenario: 删除专属文件和衍生目录
- **WHEN** 被删除记录引用原始视频、标注、运动学资产和报告 PDF
- **THEN** 系统 MUST 删除这些文件
- **AND** 系统 MUST 删除清空后的专属资产与报告目录

#### Scenario: 视频仍被其他会话引用
- **WHEN** 被删除记录的视频文件仍被其他训练记录的 `SessionVideo` 引用
- **THEN** 系统 MUST 只删除当前记录的会话视频关联
- **AND** 系统 MUST 保留该 `VideoFile` 数据库记录和原始视频文件

#### Scenario: 非法存储路径
- **WHEN** 任一待清理路径为空、逃逸上传根目录或包含无效路径成分
- **THEN** 系统 MUST 拒绝执行删除
- **AND** 系统 MUST 不删除任何未验证路径

### Requirement: 删除不得与运行中的分析任务竞争
系统 SHALL 拒绝删除存在排队中、处理中或保存结果中分析任务的训练记录。

#### Scenario: 删除运行中的任务记录
- **WHEN** 训练记录有关联的非终态分析任务
- **THEN** 系统 MUST 返回 `409 Conflict`
- **AND** 系统 MUST 保留训练记录、任务及关联文件

#### Scenario: 分析任务终态后删除
- **WHEN** 训练记录的全部分析任务均为 `completed` 或 `failed`
- **THEN** 系统 MUST 允许删除流程继续

### Requirement: 文件清理失败必须可见并可重试
系统 SHALL 在数据库关联已删除但文件系统清理失败时持久化失败的受控路径和错误信息，并提供幂等的重试方式。

#### Scenario: 文件系统删除失败
- **WHEN** 数据库关联删除成功但某个已验证文件或目录无法删除
- **THEN** 系统 MUST 记录失败路径和错误信息
- **AND** 系统 MUST 不把该次操作报告为完整成功

#### Scenario: 重试文件清理
- **WHEN** 对已记录的文件清理失败执行重试且文件仍位于上传根目录内
- **THEN** 系统 MUST 再次尝试删除该文件或目录
- **AND** 成功后系统 MUST 标记该清理项已完成
